# javasnes Project

## Version

Alpha - 0.0.1

## Status

Under Development

## Goal

The goal of this project is to provide an easy-to-use library for developing SNES games using Java. It is designed to work seamlessly with the SNES-IDE, making game development more accessible and efficient.

## Prerequisites

- **Java 8+**: Ensure you have Java version 8 or higher installed on your system.
- **Gradle 4+**: This project uses Gradle for building and managing dependencies.
- **SNES-IDE**: You must have SNES-IDE installed and configured on your system to use this library effectively.

## Setup

To get started, clone this repository and ensure all prerequisites are installed. Use Gradle to build and manage your project dependencies.
